# FORYOU logo concepts

Five original transparent SVG concepts, each on a 96x96 viewBox. Colors use currentColor. Inline the SVG to inherit CSS color; linked SVG files render black by default. Open index.html to compare standard, wordmark and reversed treatments.

- FY monogram: fy-monogram.svg
- Folded F: folded-f.svg
- FORYOU dot: foryou-dot.svg
- Interlocking loops: interlocking-loops.svg
- Label outline: label-outline.svg
